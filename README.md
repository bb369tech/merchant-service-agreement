# BB369TECH Merchant Service Agreement

Public, bilingual merchant service agreement and client intake page for BB369TECH.

## Current release

- Agreement version: 1.8
- Entry page: `index.html`
- Hosting: GitHub Pages

## Privacy and scope

- Client form data and imported contact-card content are processed in the visitor's browser.
- This repository does not contain completed customer agreements or customer records.
- Image text recognition runs in the browser; the page does not add a BB369TECH backend or database.
- Stripe checkout is handled through the payment links configured in the agreement page.
- This repository is independent and does not modify BB369TECH platform routes, merchant systems, APIs, or existing backends.

## Updating the public page

Update `index.html` in this repository. GitHub Pages will publish the updated file from the configured branch. Review the page and payment links before publishing any change.
